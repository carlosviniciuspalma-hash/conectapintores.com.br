# Conecta Pintores - Site Institucional

Este pacote contem o site completo da Conecta Pintores.

## Opção 1: subir rapidamente em hospedagem estática
Use a pasta `dist/`. Ela já contem o site compilado pronto para hospedagem.

Pode subir essa pasta em serviços como:
- Vercel
- Netlify
- Hostinger
- Cloudflare Pages
- cPanel/FTP

Em hospedagens com FTP/cPanel, envie o conteudo de `dist/` para a pasta publica do site, normalmente `public_html`.

## Opção 2: editar o projeto e gerar uma nova versão
Requisitos:
- Node.js instalado

Comandos:
```bash
npm install
npm run dev
```

Para gerar a versão final:
```bash
npm run build
```

A nova versão final será criada em `dist/`.
